# Диалоги с выбором

Реализация раздела 3.2 и строки «Диалоги» из 5.2 дизайн-документа.

## Для игрока

- Панель внизу экрана: портрет собеседника, имя, реплика и 2–4 варианта ответа.
- **W / S** (или колесо, стрелки) — выбрать, **1–4** — сразу ответить, **E / Enter / Пробел** или
  клик — ответить. Обычные реплики листаются как раньше (E).
- Серый ответ с пометкой в скобках сейчас недоступен (например, «нужен бинт»).
- `[Предъявить: …]` — ответ-улика из блокнота. Появляется, только если улика есть.
- Ответ, который даёт осколок, вспыхивает цветным камнем **после** выбора (янтарь / фиолетовый /
  белый), и фрагмент встаёт в часы отца. Опция доступности `DialogueUI.ShardColorsBeforeChoice`
  (сохраняется в PlayerPrefs) показывает цвета заранее — переключатель появится в меню настроек.
- Реплики катсцен идут в той же панели, тоже с портретами.

## Данные: `DialogueSO`

Ассет `Lone Truth/Dialogue`, папка `Assets/ScriptableObjects/Dialogue/Chapter1`.

- **Узел** (`Node`): `id`, `speaker` (пусто — внутренний голос Холта), `text`, `next` (пусто — конец),
  `setFlags` (ставятся при показе), `choices`.
- **Ответ** (`Choice`):
  - условия: `requiredFlags`, `forbiddenFlags`, `requiredItem` + `requiredAmount`,
    `presentClue` (флаг улики — ответ скрыт без неё), `hideWhenLocked` (скрыть вместо серого),
    `lockedHint`;
  - эффекты: `questId` + `outcomeId` (закрывает квест и выдаёт осколки исхода), либо
    `givesShard` + `shard` + `shards`; `setFlags` / `clearFlags`; `giveItem` / `takeItem`; `money`;
  - `next` — следующий узел.
- «Бой» как эффект — это флаг (`setFlags`), на который подпишутся сцены с врагами, когда они появятся.
- Портреты: `Assets/ScriptableObjects/Dialogue/SpeakerPortraits.asset` (имя говорящего → спрайт),
  подключён к `DialogueUI` на `P_GameUI`.

## Как запустить

- Из катсцены: шаг `Dialogue` с полем `dialogue`. В билдере — `Talking(dialogueAsset)`:
  `Talk(npc, …).AddBranch(Sequence("…", story, "", Talking(JesseDealDialogue(items))), …)`.
- Из кода: `yield return DialogueRunner.Run(dialogue)`. Вне катсцены диалог сам переводит игру
  в `GameState.Dialogue` и прячет HUD.
- Перевод: тексты в ассетах проверяет меню **Lone Truth → Localization → Check Translations**.

## Что уже на диалогах

Квест 1.2 «Раненый в сарае» (сарай, 1-16):

- Первый контакт: «Меня позвала Агнес Бирн» или «Ладно, ухожу». С поднятым револьвером Джесси
  обрывает разговор и требует убрать оружие.
- Сделка: Надежда — отдать свой бинт (нужен бинт; бинт есть в стартовом наборе Холта), Отчаяние —
  забрать карту, Истина — `[Предъявить: Гильза .45]` (показания + карта), или «Пока ничего».
  Исход закрывает квест в блокноте и выдаёт осколок.
