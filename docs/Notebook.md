# Блокнот, осколки и часы

Реализация разделов 3.2 и 4 дизайн-документа. Код — `Assets/Scripts/Notebook` (пространство имён
`LoneTruth.Investigation`) и `Assets/Scripts/UI/NotebookUI.cs`, `PocketWatchUI.cs`. Данные главы 1
собирает билдер (`Assets/Editor/LoneTruth/Chapter1NotebookBuilder.cs`) в
`Assets/ScriptableObjects/Notebook/Chapter1`.

## Для игрока

- **Tab** — открыть/закрыть блокнот (только вне катсцен; игра на паузе).
- **A / D** — раздел: Улики · Люди · Квесты · Карта. **W / S** или колесо — запись.
- В «Уликах»: **Пробел** — отметить улику, **F** — сопоставить отмеченные. Верный набор даёт вывод.
- Вверху — счётчики осколков и ключевых истин. Цифры есть только здесь.
- Часы отца в правом нижнем углу: каждый осколок встаёт в стекло цветным фрагментом со звоном
  (Надежда — янтарь, Отчаяние — фиолетовый, Истина — холодный белый). Когда в блокноте появляется
  новое, над часами пишется «Блокнот обновлён · Tab».

## Как всё связано

Всё, что знает блокнот, выводится из флагов `StoryState`, поэтому катсценам и будущим диалогам
достаточно ставить флаги.

| Запись | Когда видна |
|---|---|
| `ClueSO` (улика) | установлен её флаг (`flag`) — он же id для проверки «предъявить улику»: `Notebook.HasClue(flag)` |
| `PersonSO` (человек) | установлен `knownFlag` (пусто — известен сразу); каждая заметка — по своему флагу |
| `QuestSO` (квест) | достигнут хотя бы один этап (флаг этапа; пустой флаг первого этапа — квест виден сразу) |
| `DeductionSO` (вывод) | игрок сопоставил ровно эти улики → ставится `resultFlag`, а для ключевой истины — `ShardManager.AddKeystone` (+1 Истина) |
| Карта | локация с `scene` отмечается посещённой при загрузке сцены (флаг `visited_<Scene>`) |

## Квесты и осколки

- Исход квеста: `Notebook.CompleteQuest("1_2", "hope")` или шаг катсцены `QuestOutcome`
  (`key` — id квеста, `text` — id исхода). Ставит флаг `quest_<id>_<исход>` и выдаёт осколки
  исхода (побочный квест — 1, сюжетный выбор — 2). Повторно квест не закрывается.
- `requiredFlag` у исхода — условие, при котором вариант можно предлагать (для Истины — улика).
  Проверять его будут диалоги; сейчас это данные.
- `failFlag` — квест провален (например, `agnes_door_closed`).
- Осколки напрямую: шаг `Shard` (`key` = `Hope` / `Despair` / `Truth`, `amount`), ключевая истина —
  шаг `Keystone` (`key` = id).
- `ShardManager`: `Get`, `Total`, `BonusLevel` (0–3, по одному уровню за 3 осколка),
  `IsEndingAvailable` (Истинная — 3 ключевые истины и 7 Истины; Надежда — Надежды не меньше
  Отчаяния; Отчаяние — всегда). Сами бонусы к здоровью/урону/торговле пока не применяются.

  «Курок Кэллахана» с исходами и осколками.
- Карта главы: 13 мест; построенные отмечаются по посещению.
