# Локализация

Игра по умолчанию запускается на английском. Язык переключается в правом верхнем углу экрана
(EN / RU), выбор сохраняется в `PlayerPrefs` (ключ `language`). Позже переключатель переедет в меню
настроек, вызов тот же: `Loc.SetLanguage("ru")`.

## Как устроено

- Исходный язык текстов — **русский**. Русская строка и есть ключ перевода, поэтому сцены, билдер
  (`Chapter1StoryBuilder`) и предметы пишутся по-русски, как раньше.
- Каждый другой язык — один файл `Assets/Resources/Localization/<код>.json`:

  ```json
  {
    "code": "en",
    "name": "English",
    "entries": [
      { "key": "Поговорить", "value": "Talk" },
      { "key": "Утро.\nДень первый.", "value": "Morning.\nDay one." }
    ]
  }
  ```

- Текст переводится в момент вывода (`Loc.T`): диалоги, титры, всплывающие сообщения, цель,
  подсказки взаимодействия, названия предметов. Уже показанный текст перерисовывается при смене языка.
- Нет перевода — показывается русский оригинал, а в редакторе в консоль пишется
  `[Loc] No "en" translation for: …`.

## Добавить язык

1. Скопировать `en.json` в, например, `de.json`.
2. Поменять `"code": "de"` и `"name": "Deutsch"`, перевести все `value`. Ключи (`key`) не трогать.
3. Всё — переключатель сам покажет `DE`. Если у языка своя письменность (не латиница/кириллица),
   нужен шрифт с её глифами вместо PT Sans (`Assets/Scripts/UI/UIFonts.cs`).

## Добавить или изменить текст

- Новая реплика по-русски → добавить запись с этим ключом в каждый языковой файл.
- Изменили русскую реплику → ключ поменялся, обновите `key` в языковых файлах.
- Проверка: меню **Lone Truth → Localization → Check Translations**. Оно проходит все сцены из
  Build Settings и все ScriptableObject и выводит в консоль строки без перевода для каждого языка.
- Строки, которые формирует код, проверка не видит — они перечислены ниже и уже есть в `en.json`.
  Для текста с подстановкой используйте `Loc.Format("Заряжено: {0}", n)`; в переводе `{0}`
  должен остаться.

| Ключ | Где |
|---|---|
| `ЦЕЛЬ` | `GameUI.SetObjective` |
| `Q / колесо — выбрать   ·   G — применить   ·   R — перезарядить` | `InventoryBarUI` |
| `{0} — в руке`, `{0} — в кобуре`, `{0} — использовано`, `Заряжено: {0}`, `Барабан полон.`, `Сейчас это не нужно.`, `Здесь это не пригодится.` | `InventoryActions` |
| `Получено: {0}`, `Получено: {0} ×{1}`, `Получено: ${0}` | `CutsceneSequence` |
| `заперто`, `Заперто.`, `Открыто.` | `SceneTransitionDoor` |
| `закрыто` | `TransitionStub` |
| `ПКМ / Ctrl — прицелиться   ·   E / ЛКМ — выстрел` | `InventoryBarUI` |
| `Не то место, чтобы хвататься за револьвер.`, `Револьвер в кобуре. …`, `Барабан пуст. R — перезарядить.` | `WeaponController` (поля в инспекторе P_Player) |
| `Поговорить`, `Осмотреть` | `CutsceneInteractable`, билдер |
| `Подобрать: {0}` | `InteractableItem` |
